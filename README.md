# AI-Based Attendance System

## Description
This is a simple attendance management system built using Python. It also includes a basic machine learning model to predict student attendance.

## Features
- Mark attendance
- View attendance records
- Calculate attendance percentage
- Predict attendance using AI (Decision Tree)

## Technologies Used
- Python
- Pandas
- Scikit-learn

## How to Run
1. Install required libraries:
   pip install pandas scikit-learn

2. Generate dataset:
   python generate_data.py

3. Run program:
   python main.py
